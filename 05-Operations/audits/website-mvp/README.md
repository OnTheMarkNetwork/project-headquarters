# Website MVP Audit Archive

Historical and recurring OTMN Website MVP Audits belong here.

## Conventions

- Use the audit period end date in the filename: `YYYY-MM-DD-website-mvp-audit.md`.
- Preserve completed audits as historical snapshots rather than living documents.
- Keep the audit period, audit date, and previous-audit relationship explicit.
- Future audits should retain the same basic structure so progress can be compared over time.

The first historical audits will be added in a separate follow-up task after this archive structure is established.
