# OTMN Roadmap Info v1.0

## Purpose

Provide a lightweight place in Operations HQ for roadmap-shaping concepts, operating loops, and structural ideas that may be useful for future planning but are not yet formal roadmap commitments.

## Idea → Candidate → Work

```text
IDEA
  ↓
CANDIDATE
  ↓
WORK
```

### Idea

This might be useful. Capture it without creating an obligation.

### Candidate

This may deserve a place in OTMN. Research or evaluate it; no implementation commitment yet.

### Work

We have decided to do it. Promote it into the appropriate issue, project, standard, implementation task, documentation task, content task, or other real work.

> **An idea does not create an obligation.**

## Operating guidance

- Roadmap Info preserves useful discoveries without turning them into commitments.
- Active work remains intentionally constrained.
- Candidates should be promoted only when current context, evidence, dependencies, and value justify doing so.
- This file is information and guidance, not a new approval gate or project-management system.
- Keep the structure lightweight. Let real use demonstrate whether additional structure is needed.

## Relationship to the OTMN operating system

- **GitHub** → system of record for durable OTMN work, standards, decisions, and documentation.
- **ChatGPT** → analysis and intelligence layer.
- **Google Workspace** → potential complementary working layer only when a demonstrated need exists.

The system relationship above is a working concept, not an architecture commitment.

## Guiding principle

> **Build the foundation. Prove the workflow. Let the next layer earn its way into existence.**

> **Capture broadly. Promote selectively.**
