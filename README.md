# OTMN Project Headquarters

Central planning, documentation, architecture, governance, and long-term project direction for OnTheMarkNetwork.

## Headquarters structure

- `01-Vision/` — purpose and direction
- `02-Roadmap/` — major initiatives, phases, and sequencing
- `03-Projects/` — durable project-level planning and records
- `04-Standards/` — approved operating standards
- `05-Operations/` — recurring workflows and GitHub PM operations
- `06-Architecture/` — durable technical architecture
- `07-Communities/` — network-level community direction
- `08-Brand/` — durable brand guidance
- `09-Legal/` — public legal, privacy, ownership, and licensing documentation
- `10-Archive/` — intentionally retained superseded material

## GitHub operating model

GitHub issues and projects are the execution layer. Headquarters documentation provides durable context and should not become a duplicate task tracker.

The current PM baseline is documented in `05-Operations/OTMN-GitHub-PM-Foundation-v1.0.md`.

## Repository principle

Each OTMN repository should have a clear purpose, appropriate visibility, a useful README, and a defined relationship to the organization roadmap. Public repositories should contain only information appropriate for public visibility.

## OTMN operating principle

Build the foundation before the growth requires it — while resisting the temptation to build foundation that has not yet earned its place.
