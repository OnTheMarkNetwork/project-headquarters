# OTMN Roadmap v1.0

**Status:** Active planning baseline
**Scope:** OnTheMarkNetwork organization

## Purpose

The roadmap defines the major areas of OTMN work and their intended sequence. GitHub issues and projects remain the execution layer; this document records durable direction rather than duplicating task lists.

## Current foundation

1. **Vision** — establish the purpose and direction of OTMN.
2. **Roadmap** — maintain major initiatives and sequencing.
3. **Projects** — document project-level work that needs durable context.
4. **Standards** — define only the operating rules that have demonstrated a need.
5. **Operations** — run the GitHub PM, GIA, review, and recurring operating workflows.

## Organizational areas

6. **Architecture** — document shared technical architecture, system relationships, and durable technical decisions.
7. **Communities** — document community structure, participation models, and network-level community initiatives.
8. **Brand** — maintain durable brand direction, identity rules, and reusable brand references.
9. **Legal** — maintain legal, privacy, ownership, and public-use documentation as needed.
10. **Archive** — preserve superseded material when historical context is useful without allowing it to drive current operations.

## Sequence

### Phase 1 — Foundation
- Complete the GitHub PM foundation.
- Establish GIA as the default execution workflow.
- Keep labels, templates, standards, and documentation intentionally small.
- Establish repository visibility and privacy boundaries.

### Phase 2 — Operating structure
- Complete the core headquarters areas and READMEs.
- Establish the repository registry and ownership/visibility map.
- Connect major projects to the roadmap without duplicating issue tracking.

### Phase 3 — Network growth
- Expand architecture, communities, brand, and legal documentation only when active work requires it.
- Add project-specific repositories as justified by actual work.
- Review and remove structures that do not provide continuing value.

## Roadmap rule

The roadmap is directional. It does not authorize building everything listed here immediately. OTMN should add detail when the work becomes real and remove or defer items that no longer earn their place.

> Sometimes progress isn't another thing you ship. Sometimes progress is knowing what not to build yet.
