# OTMN Repository Registry v1.0

**Status:** Initial organization baseline

This registry records the known OTMN organization repositories and their intended roles. It is a planning reference, not a substitute for repository READMEs.

| Repository | Purpose | Visibility | Role |
|---|---|---|---|
| `OnTheMarkNetwork/.github` | Organization-level community health files and shared GitHub defaults | Public | Organization infrastructure |
| `OnTheMarkNetwork/project-headquarters` | Central planning, roadmap, standards, architecture, governance, and operations | Public | Organization headquarters |

## Repository rules

- Every repository should have a clear purpose and a useful README.
- Visibility should match the information the repository contains.
- Public repositories must not contain private, confidential, or sensitive material.
- Project repositories should link their purpose to the organization roadmap when appropriate.
- A repository should not be created merely because an area exists in the roadmap.
- Repository lifecycle decisions follow `04-Standards/OTMN-Repository-Lifecycle-Standard-v1.0.md`.

## Future repositories

Additional repositories may be added when there is a demonstrated need for separation of code, content, collaboration, or access control. The registry should be updated when that happens.
