# OTMN Core Idea v1.0

**OTMN is a network for developing good ideas into useful things. We provide the foundation, connections, and communities that help an idea prove itself and grow into whatever it is meant to become.**

## Context

This is the canonical OTMN Core Idea. It describes what OTMN fundamentally does without limiting the network to a particular technology, platform, community, or project.

It complements the OTMN Manifesto and operating principles rather than replacing them:

- The **Core Idea** describes what OTMN fundamentally does.
- The **Manifesto** describes why OTMN exists and what it believes.
- The **operating principles** describe how OTMN works.

The Core Idea should remain intentionally concise. Expand or replace it only when actual OTMN use demonstrates a durable need.
