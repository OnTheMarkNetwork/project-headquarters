# OTMN GIA Standard v1.0

**Status:** Placeholder — not yet approved

## Purpose

This document will define the official OTMN GIA operating standard.

## Planned scope

- Supported GIA commands and task types
- Repository and path selection
- Create, modify, organize, issue, branch, and pull-request workflows
- Direct-to-`main` rules
- Human approval requirements
- Safety and ambiguity handling
- Commit and naming conventions

## Development note

This standard is intentionally not being finalized yet. The GIA pilot will provide the real-world examples needed to determine which rules are useful and which are unnecessary.
